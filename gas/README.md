# COFFEE TIME 記録・通知サーバー（Google Apps Script）

ESP32 から届いた「+1」「補充」を Google スプレッドシートに記録し、
残りが 3 杯になった瞬間に「設定」シートの宛先（最大 4 人を想定）へメールを送る。

## 初回セットアップ（会社の Google Workspace アカウントで実施）

1. Google ドライブで新しいスプレッドシートを作る（名前例: `COFFEE TIME 記録`）
2. メニュー **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダーの `Code.gs` の中身を貼り付けて保存（Ctrl+S）
4. 上部の関数選択で **setup** を選び **実行**
   - 初回は「承認が必要です」→ 自分のアカウントを選び → 許可
   - 下の「実行ログ」に `TOKEN = xxxxxxxx…` が出る（ESP32 の合言葉）
5. スプレッドシートに戻り、**設定** シートの A2〜A5 に通知先 4 人のメールアドレスを入れる
6. Apps Script に戻り、関数 **testMail** を実行 → 4 人にテストメールが届くか確認
7. 右上 **デプロイ → 新しいデプロイ**
   - 種類の選択（歯車）: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（ESP32 はログインできないため。合言葉で保護している）
   - **デプロイ** → 表示された **ウェブアプリの URL** をコピー
8. `firmware/include/secrets.h` の `GAS_URL` に URL、`GAS_TOKEN` に 4 の TOKEN を貼って保存

## コードを変更したとき

Apps Script でコードを直したら **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン → デプロイ**。
こうすると URL は変わらないので、ESP32 の書き換えは不要。

## 設定

| 項目 | 場所 |
|---|---|
| 通知先 | スプレッドシート「設定」シートの A 列 |
| 通知する残り杯数 | `Code.gs` の `NOTIFY_AT` |
| 差出人の表示名 | `Code.gs` の `SENDER_NAME`（差出人アドレスは実行アカウントのまま） |
